# 🛡️ Project Development Log: FakeShield AI

This log serves as a chronological record of the development hurdles and milestones of the FakeShield project.

---

### [2024-01-15] - Initial Setup
- Started the project using React and Express.
- Struggle: Had issues with the SQLite pathing in the backend.
- Fixed: Used `path.join(__dirname, 'database.db')` to ensure it works across different environments.
- Decision: Chose `better-sqlite3` over `sqlite3` for better performance and synchronous API.

### [2024-01-22] - Auth & Security
- Implemented JWT authentication.
- Bug: Token was expiring too quickly during testing.
- Fixed: Set expiration to 24h for now.
- NOTE: Need to remember to hash the passwords before saving! (Used bcrypt).

### [2024-02-05] - NLP Engine Phase 1
- Created the keyword-based heuristic analysis.
- Frustration: Clickbait words are hard to categorize perfectly.
- Solution: Added a weighted system where 'microchip' has a higher 'fake' score than just 'shocking'.
- Added 'sentiment' detection to check for fear-mongering language.

### [2024-02-18] - Frontend UI Polish
- Building the 'Cyberpunk' dark theme.
- CSS Issue: The glow effects on the cards were causing lag on my laptop.
- Optimization: Used `box-shadow` instead of complex SVG filters for the neon effect.
- Added the Breaking News ticker. It took way too long to get the animation smooth.

### [2024-03-02] - Admin Features & Logs
- Added role-based access control.
- Test: Logged in as 'user' and tried to access `/admin`. It redirected successfully.
- Added activity logs so I can see what the 'journalist' role is doing.

### [2024-03-10] - Final Testing & Bug Squashing
- Found a bug where the 'Real' and 'Fake' probability bars didn't add up to 100% due to rounding.
- Fixed using `Math.round(val * 10) / 10`.
- Project feels stable now. Ready for presentation.
